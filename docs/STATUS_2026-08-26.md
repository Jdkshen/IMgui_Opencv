## 本轮完成

| 项目 | 当前结果 |
| --- | --- |
| 16 任务输入内存 | 待执行队列只保存引用计数图像头；任务进入最多 4 个活动 worker 后才深拷贝输入；捕获帧到任务映射不再重复复制；结果图通过移动所有权发布 |
| 内存异常边界 | worker 输入复制捕获 `std::bad_alloc` 与 OpenCV 异常，错误返回主线程并写入日志，不再让后台线程异常终止进程 |
| 模型并发 | 原来统一的模型全局锁拆成 ONNX YOLO、OpenCV YOLO 和 OCR 三把锁；同一后端保持安全串行，不同后端允许并行 |
| YOLO 缓存 | 任务执行为不可变输入帧分配本轮 token；命中时跳过整图 FNV 哈希；单条缓存改为 8 条 LRU，减少多相机、多 ROI 互相顶掉 |
| 华睿说明 | 文档已与实现统一为同步 `IMV_GetFrame`/`IMV_ReleaseFrame`，不再误写成回调取帧 |
| 回归保护 | 新增任务并行输入副本峰值指标和 8 任务回归，要求待执行队列零整图深拷贝、活动输入不超过 worker 上限 |
| 测试结构 | 将任务并行与输入内存回归从 7000 行级主测试文件拆到 `RegressionTaskSchedulingTests.cpp`，后续按同样方式继续迁移相机和硬件场景 |
