## 1. 本轮界面调整

- 工具流程图不再嵌入右侧工具面板；点击“打开流程图窗口”后在独立 ImGui 窗口显示，可单独移动、停靠或关闭。
- 独立流程图改为按可用宽度自动换行；常规窗口下 16 个工具按 4 列多行显示，不再需要把底部横向滚动条拖到末端。跨行顺序线重新布线，Result ROI/Fixture 依赖按紫色/橙色区分，长标题限制在节点内并提供悬停完整名称，点击节点可定位对应工具卡片。
- 右侧工具列表统一工具卡片的展开按钮、PNG 图标、标题、序号和删除按钮位置，长列表保持滚动。
- “添加工具”弹窗把 18 个工具重新整理为“输入与预处理、定位与识别、区域与几何、分析与测量、实验工具”五类；增加名称/用途搜索、分类数量、工具总数和两行用途说明，选中工具后自动关闭弹窗。
- 任务设置中的“绑定相机”改为固定标签列与自适应下拉框列，窄侧栏下文字不会被挤出可视区域；长输入优先级提示自动换行。
- 执行区为“任务并行”状态行预留固定高度，底部“普通模式/运行模式”和“`N 个工具`”状态不再被日志窗口遮挡。
- 任务结果总览为“本轮总耗时”预留独立标题列，常规宽度下始终完整显示；窗口较窄时自动换到标题下方，不再因空间不足直接隐藏。
- 任务卡片、详情和工具行统一耗时格式：小于当前显示精度时显示 `<0.1 ms` 或 `<0.01 ms`，秒级耗时自动改用秒，未执行项显示 `--`。
- 各工具参数面板继续使用公共表单行布局，标签列与控件列保持一致。
- 工具 ROI 改为显式绑定：卡片显示“未绑定（执行整图）”时不再自动继承画布 ROI；普通执行、任务并行快照和实时 YOLO 使用相同规则。
- 空配方和无正式任务的旧配方保持空任务列表；删除最后一个任务后不再自动创建“任务01”，只有用户点击“+ 新建任务”才新增正式任务。
- ROI“侧边栏”窗口改为启动时默认隐藏，左侧默认只保留任务列表，因此不会再出现“侧边栏 / 任务列表”两个启动标签；需要 ROI 控制面板时可从“查看(V) → 侧边栏控制”重新打开。

- 结果 ROI 新增“选择两个结果”：A、B 可选择同一上游的不同结果序号，也可选择两个不同上游；点点距离把两项分别转成中心点，线线角度/线线距离要求两个线结果，点线距离使用“中心点 A + 线段 B”。第二来源已纳入配方、工具增删/移动重映射、稳定 ID 恢复、跨任务并行回退、运行前校验和执行图。
- A、B 的“结果序号”数字控件改为描述性结果下拉框；选项直接展示类型、标签/文字、中心坐标或线段端点和分数，并与实际解析使用同一过滤、排序和线结果约束。上游未执行、筛选为空或旧选择越界时显示明确占位说明。
