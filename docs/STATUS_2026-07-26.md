## 本轮完成内容

### 任务管理

- 正式任务上限为 16 个，任务顺序同时用于执行顺序和结果卡片顺序。
- 支持新建、重命名、排序、启用、禁用和删除任务。
- 工具可直接加入当前任务，任务内工具保持独立参数和顺序。
- 禁用任务从执行顺序、相机判断、并行候选和结果总览中统一排除。

### 任务输入

- 每个任务可独立绑定单图或递归图片文件夹。
- 文件夹每轮推进一张，同一任务内全部工具共用本轮图片。
- 单步执行在任务内部保持图片不变，下一轮第一步才推进图片。
- 图片路径、文件夹路径、位置、数量和相机优先设置写入配方。

### 相机优先

- 任务可优先使用设备页中已连接的工业相机。
- 相机未连接时直接使用任务图片或公共图片。
- 已连接相机抓帧失败时，执行请求仍会完成并进入备用图片路径，不再卡住工具链。
- 相机优先只选择输入，不会自动连接设备；Windows USB 相机建议优先使用 `dshow`。

### 执行与结果

- 支持执行全部、执行当前任务、全部单步和当前任务单步。
- 单步高亮使用过滤后任务工具对应的真实全局索引。
- “任务并行”最多并发 4 个启用任务；跨任务依赖时自动回退顺序执行。
- 结果总览按启用任务顺序显示，禁用任务和无工具的“未分组”不生成空卡片。
- 结果总览标题显示整轮墙钟时间，任务和工具区域保留局部耗时。

### 代码清理

- 删除未加入工程且全仓库无调用的旧自绘标题栏 `UI/AppTitleBar.*`；主框架和菜单栏继续由 `UI/DockSpaceHost.*` 负责。
- 删除 `ImageState` 中无调用的原图、宽度、高度和版本号可写引用，避免绕过统一状态更新入口。
- 工具面板映射改为 `ToolsWindow.cpp` 私有状态，`ToolsWindow.h` 不再向所有调用方暴露工具实例和容器依赖。
- OpenCV YOLO type 11 注册器由含糊的旧名称改为职责名称，注册行为和配方 type 保持不变。
- 保留旧配方迁移、稳定工具 ID、结果 ROI/Fixture 索引回退和模板读写兼容层。
