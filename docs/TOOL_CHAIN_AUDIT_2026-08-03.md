# 工具输入、ROI、上下游与结果显示统一检查

> 检查日期：2026-08-03。范围覆盖工具类型 0～17，包括实验工具和原图工具。

## 统一验收规则

每个工具必须同时满足以下规则：

1. 输入来源：能够明确使用任务图片、公共图片或前置工具处理图；来源无效时在运行前给出中文错误。
2. 本工具 ROI：未绑定时执行整图；显式绑定后仅使用绑定 ROI；不得偷偷继承画布上其他 ROI。
3. 结果 ROI：只能选择具有空间输出能力的前置工具；区域、检测框、文本框和线段使用统一解析与排序规则。
4. Fixture：只能引用可提取位置的前置结果；工具移动、复制、删除和配方重载后使用稳定 `toolId` 恢复引用。
5. 结果输出：`status/message/timing` 与区域、检测框、线段、文本、测量、处理图六类通道保持一致。
6. 显示：工具卡片、主图叠加、任务总览和任务详情使用同一份 `ToolResult`，空结果、跳过、失败和错误均有明确状态。

## 自动化与界面验收

> “待截图”表示需要在实际窗口中确认字体、缩放、主题和窄窗口裁切；代码路径和自动回归已经通过，不代表替代人工视觉验收。

- Release x64 主程序和回归工程必须为 0 错误。
- 完整 `RegressionTests.exe` 必须通过。
- 结果 ROI 至少覆盖区域、检测框、文本框、线段，以及 A/B 双来源组合。
- 检查未绑定 ROI 执行整图、显式绑定 ROI、工具移动后引用恢复和删除上游后的运行前阻止。
- 深色、浅色主题分别检查工具卡片、主图叠加和任务结果详情。
- 1280×720 与 1920×1080 下不得出现参数、状态、耗时或结果文字被裁切。
