# 2026-07-30 双图形后端状态

> 本页记录 DX12 优先、DX11 自动回退改造完成后的代码、构建、测试和发布包快照。源码和自动化测试始终高于本状态快照。

## 1. 完成内容

- 新增独立 `Core/DX11Context.h/.cpp`，实现 D3D11 设备、交换链、RenderTarget、遮挡检测、Resize、ImGui DX11 后端以及纹理创建、上传和释放。
- 完整保留 `Core/DX12Context.h/.cpp`；仅增强部分初始化失败时的安全清理与状态复位。
- 新增 `Core/RenderBackend.h`，通过 `IRenderBackend` 统一两套后端的初始化、清理、新帧、遮挡、窗口缩放、渲染/Present、等待空闲和纹理生命周期接口。
- 新增 `Core/DX12Backend.h/.cpp`，把保留的 DX12 实现接入公共契约；DX12 纹理上传缓冲按帧槽复用，避免连续图像更新覆盖 GPU 尚未读取的数据。
- 新增 `Core/GraphicsBackend.h/.cpp` 作为唯一门面。启动默认先尝试 DX12；失败时记录原因并自动回退 DX11。
- `Windows_imgui.cpp`、`ImageLoadController`、`PreviewTextureCache` 和各 UI 窗口不再读取 D3D11/D3D12 纹理或描述符类型，只使用通用纹理句柄与 `ImTextureID`。
- DX11 与 DX12 共用同一套 ImGui 上下文、Docking、字体加载、图片显示、缩放平移、多视口、窗口 Resize 和最大化业务逻辑。
- 任务列表与控制面板共用左侧 DockSpace 停靠节点，通过标签页切换；关闭后重新打开仍回到左栏，不再以浮动窗口覆盖图片。
- 工程文件已加入新源文件，并在 Debug/Release x64 配置链接 `d3d11.lib`。

## 2. 后端选择和日志

正常启动无需配置：

```text
尝试 DirectX 12
  ├─ 成功：记录“渲染后端已选择: DirectX 12”
  └─ 失败：记录失败原因 → 记录自动回退 → 尝试 DirectX 11
                    ├─ 成功：记录回退成功与选中的 DirectX 11
                    └─ 失败：记录 DX11 回退失败并终止图形初始化
```

发布前可使用诊断覆盖强制走 DX11：

```powershell
$env:IMGUI_OPENCV_RENDER_BACKEND = "dx11"
.\x64\Release\Windows_imgui.exe
Remove-Item Env:IMGUI_OPENCV_RENDER_BACKEND
```

该变量只用于验证回退路径，产品默认仍是 DX12 优先。

## 5. 维护约束

- UI、算法和业务模块不得新增 `ImGui_ImplDX11_*`、`ImGui_ImplDX12_*`、`ID3D11*`、`ID3D12*` 或描述符句柄依赖。
- 新增纹理用途时，通过 `GraphicsBackend` 或后端无关缓存创建、上传、查询和释放。
- 改动窗口 Resize、字体重建、ImGui Viewports 或图片显示后，必须同时验证默认 DX12 与强制 DX11 路径。
- 后续发布应重新记录 EXE/ZIP 哈希，不沿用本页快照。
