# Runtime Files

> Documentation sync: 2026-07-25. This file has been reviewed against `master` after the `codex/p0-p4-release` merge; see `docs/STATUS_2026-07-25.md` for the consolidated change summary.


This directory is used locally for OpenCV, ONNX Runtime, DirectML, NCNN, and MSVC runtime binaries.

Large `*.dll` and `*.lib` files are intentionally not committed through normal Git. Keep them locally, restore them from a release package, or manage them through Git LFS before building.
