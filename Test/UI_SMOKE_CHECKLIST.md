# UI 固定分辨率冒烟清单

> 文档同步日期：2026-08-25。已加入独立流程图、窄侧栏标签、工具弹窗 PNG 图标、统一结果输出、上下游来源过滤、任务相机输入隔离、Bootstrap 双布局、底部状态栏和高 DPI 窗口专项检查；正式截图基线仍需在候选包上补齐。

启动候选包前先执行 `Windows_imgui.exe --diagnostic-only`；Visual Studio 调试 Bootstrap 时还需确认它从父级构建目录启动主程序，且不会弹出“缺少 Windows_imgui_core.exe”整包诊断。

每次候选发布包至少执行以下矩阵。截图文件名统一为
`<resolution>/<step>-<theme>.png`，用于后续像素差异基线。

## 分辨率矩阵

| 编号 | 客户区分辨率 | 缩放 | 用途 |
| --- | --- | --- | --- |
| R1 | 1280 x 720 | 100% | 最小生产屏幕 |
| R2 | 1920 x 1080 | 100% | 标准产线屏幕 |
| R3 | 2560 x 1440 | 125% | 高分屏与 DPI |
| R4 | 3120 x 2080 | 150% | 3:2 高分屏及现场笔记本 |

深色、浅色主题均执行 R1 和 R2；R3、R4 至少执行深色主题。

## 截图比较规则

- 忽略时间戳、FPS、执行耗时、日志正文和鼠标光标区域。
- 其余区域建议使用结构相似度 SSIM；低于 `0.985` 时人工复核。
- 基线只能在确认视觉变更符合需求后更新，并在变更记录中写明原因。
- 任一分辨率出现控件裁切、重叠、不可达或任务/图片状态不一致，候选包不得发布。
